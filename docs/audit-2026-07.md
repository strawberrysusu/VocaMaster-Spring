## 교훈 (테스트 구조)

클래스 `@Transactional` 테스트는 **운영 커밋 경계를 검증하지 못한다** — P1-1이 그린이었던 이유.
트랜잭션 경계 자체가 관심사인 테스트(인증 회전, Import 원자성)는 ConcurrencyTest처럼
`NOT_SUPPORTED` + 수동 정리 패턴으로 작성할 것.
